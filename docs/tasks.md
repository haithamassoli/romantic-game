# مراحل تنفيذ الموقع

**المرجع:** [PRD](docs/PRD.md). تنطبق على كل مرحلة واجهة عربية باتجاه RTL، وتصميم للهاتف، ومحتوى للبالغين فقط، وحق الطرفين في التخطي والإيقاف. لا يحتاج الزوجان إلى حساب أو دفع، ولا يشمل المنتج محادثة أو محتوى ينشره المستخدمون.

## المرحلة 1: دليل وضعيات قابل للاستخدام

**الناتج:** يستطيع زائر بالغ تصفح وضعية مناسبة وحفظها على جهازه.

- [x] استبدال قالب Next.js بواجهة عربية للهاتف، مع تأكيد العمر قبل عرض المحتوى الصريح.
- [x] إعداد Convex ونموذج محتوى للوضعيات والأنشطة: حالة النشر، الصورة، النص البديل، الصعوبة، وسوم الجرأة، الموضوعات، والقيود الجسدية.
- [x] إدخال مجموعة أولية من الوضعيات بصور يملك الناشر حقوقها، بلا ملامح وجوه، مع شرح واعتبارات الراحة والسلامة.
- [x] بناء قائمة الوضعيات وصفحة التفاصيل والتصفية حسب الصعوبة والتفضيلات والقيود.
- [x] حفظ المفضلة والمستبعد محليًا، مع زر لمسح البيانات المحلية.
- [x] التحقق على هاتف فعلي أو بمحاكاته من القراءة بالعربية، التكبير، النص البديل، وتبقي المفضلة بعد إعادة فتح الصفحة.

**تكتمل عندما:** يصل الزائر إلى وضعية مناسبة، يفتح تفاصيلها، ويحفظها أو يستبعدها دون حساب.

## المرحلة 2: ألعاب وتحديات على جهاز واحد

**الناتج:** يلعب الزوجان على جهاز واحد ضمن الحدود التي يقبلها كلاهما.

- [x] بناء إدخال حدود الطرفين بالتتابع مع إخفاء إجابة الطرف الأول، وحفظ التفضيلات العامة محليًا دون حفظ الإجابات السرية.
- [x] تطبيق مرشح واحد يستبعد أي نشاط يرفضه أحد الطرفين، مع حالة واضحة إذا لم يبق نشاط مناسب.
- [x] بناء بطاقات التحدي، عجلة الاختيار، ومكتبة التحديات الواقعية مع مؤقت اختياري.
- [x] إتاحة التخطي وإعادة الاختيار وإنهاء الجلسة في كل خطوة، دون نقاط أو عقوبات.
- [x] اختبار أن السحب والتصفية لا يعرضان نشاطًا مرفوضًا، وأن مسح البيانات يزيل التفضيلات والمفضلة والتقدم.

**تكتمل عندما:** يبدأ الزوجان لعبة، يصلان إلى تحدٍّ مقبول، أو يغادران الجلسة فورًا دون فقدان التحكم.

## المرحلة 3: التوافق ومسار الليلة

**الناتج:** يحصل الزوجان على اقتراحات مشتركة دون كشف اختيارات أحدهما غير المتطابقة.

- [x] بناء لعبة توافق الرغبات ولعبة اكتشاف الوضعيات بإدخال سري متتابع، ثم إظهار التقاطع فقط بعد اختيار الطرفين.
- [x] بناء مسار الليلة من أنشطة مسموحة وفق المدة والجرأة المختارتين، مع التخطي والإيقاف.
- [x] حفظ التقدم المحلي غير السري وإتاحة بدء جلسة جديدة دون بقايا من اختيارات الجلسة السابقة.
- [x] اختبار عدم ظهور الاختيارات الخاصة في النتائج أو التخزين المحلي أو روابط المشاركة، واختبار حالة عدم وجود تطابق.

**تكتمل عندما:** يظهر توافق صحيح أو رسالة بعدم وجوده، ويكتمل مسار قصير دون عرض نشاط خارج الحدود.

## المرحلة 4: جلسة مشتركة على هاتفين

**الناتج:** يدخل الزوجان جلسة واحدة برابط أو رمز، وتتزامن خطوات الألعاب بين الهاتفين.

- [x] إنشاء جلسات Convex بمعرفات يصعب تخمينها، ورمز انضمام مؤقت، وحد أقصى لطرفين، دون حسابات للزوجين.
- [x] مزامنة الحدود والاختيارات والنتائج والتخطي والإيقاف مع إبقاء اختيارات كل طرف سرية حتى اكتمال الإجابتين.
- [x] عرض حالات الدعوة والانتظار والانقطاع وإعادة الاتصال، ومنع الطرف الثالث من الانضمام.
- [x] حذف بيانات الجلسة عند إنهائها أو بعد 24 ساعة من الخمول.
- [x] تجربة كل لعبة على متصفحين منفصلين، واختبار الانقطاع، إعادة الاتصال، انتهاء الصلاحية، ومحاولات التخمين أو الانضمام الإضافي.

**تكتمل عندما:** يرى الطرفان الحالة نفسها، ولا يحصل طرف أو زائر ثالث على اختيارات سرية أو جلسة غير مصرح بها.

## المرحلة 5: إدارة المحتوى

**الناتج:** يضيف الناشر المحتوى ويعدله دون تعديل الشيفرة.

- [x] حماية دخول الناشر إلى الإدارة دون فرض حسابات على الزوجين.
- [x] بناء إضافة وتعديل وإخفاء ونشر الوضعيات والصور والبطاقات والتحديات.
- [x] إلزام الناشر بالوسوم اللازمة للتصفية، والنص البديل، وبيانات حقوق الصورة قبل النشر.
- [x] إعداد المحتوى العربي الأولي لكل نوع لعبة ومراجعته من حيث الوضوح والجرأة والرضا المتبادل.
- [x] اختبار عدم ظهور المسودات والمحتوى المخفي للزوار، وعدم تعطل جلسة جارية عند تعديل محتوى منشور.

**تكتمل عندما:** ينشر الناشر وضعية وتحديًا جديدين، ثم يخفيهما من الإدارة دون تدخل مطور.

## المرحلة 6: جاهزية النشر

**الناتج:** نسخة قابلة للإطلاق في الدول التي يحددها الناشر.

- [ ] تحديد دول الإتاحة، ثم تطبيق متطلبات التحقق من العمر وإتاحة المحتوى الجنسي لكل دولة قبل النشر العام.
- [ ] مراجعة حقوق جميع الصور والمحتويات، والتأكد من أن الرسوم تصوّر بالغين فقط وبلا ملامح وجوه.
- [x] مراجعة الخصوصية: لا أسماء أو بريد أو ملفات شخصية؛ تخزين الاختيارات السرية للجلسة فقط؛ حذف بيانات Convex المنتهية؛ زر مسح البيانات المحلية.
- [x] اختبار المسارات الأساسية على أجهزة وأحجام شاشة مختلفة، مع لوحة المفاتيح وقارئ الشاشة، وتحسين تحميل الصور.
- [x] تشغيل `pnpm format` و`pnpm check` و`pnpm build`، ثم تنفيذ تجربة قبول كاملة على جهاز واحد وهاتفين قبل الإطلاق.

**تكتمل عندما:** تنجح تجربة القبول، وتُحسم متطلبات الدول وحقوق المحتوى، وتعمل النسخة المنشورة دون حسابات أو مدفوعات.
